# Bootstrap

Mission zero. On first invocation in a project with no `wiki/index.md`, f-chief dispatches explorers to map the project and writes the initial overview, terms and conventions from their notes. On an empty folder it switches to greenfield mode: a draft overview page, no explorers, and the toolchain is chosen during the first interview.
