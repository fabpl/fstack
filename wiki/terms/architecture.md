# Architecture

How one run's change is built: the files and modules it touches, the interfaces and data between them, the shared files and their entries, and the choices behind them. Written per run in `architecture.md` after the spec, approved by the user, binding on tickets and implementers. Distinct from the `overview` page, which describes the whole project and outlives the run.
